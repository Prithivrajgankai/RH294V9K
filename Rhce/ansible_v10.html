Configure repositories on all nodes — adhoc.yml

baseos + appstream via yum_repository
▸
Task
Create a playbook adhoc.yml for configuring the repository on all nodes.
  1. Repository baseos:
    • Name = baseos
    • Description = Baseos Description
    • URL = http://content/rhel10.0/x86_64/dvd/BaseOS
    • GPG is enabled; Gpgkey = http://content/rhel10.0/x86_64/dvd/RPM-GPG-KEY-redhat-release
    • Repository is enabled.
  2. Repository appstream:
    • Name = appstream
    • Description = App Description
    • URL = http://content/rhel10.0/x86_64/dvd/AppStream
    • GPG is enabled; Gpgkey = http://content/rhel10.0/x86_64/dvd/RPM-GPG-KEY-redhat-release
    • Repository is enabled.
Answer
✓ Solution
/home/student/ansible/adhoc.yml
---
- name: Creating yum repository
  hosts: all
  tasks:
    - name: Create BaseOS Repository
      ansible.builtin.yum_repository:
        name: "baseos"
        description: "Baseos Description"
        baseurl: http://content/rhel10.0/x86_64/dvd/BaseOS
        gpgcheck: yes
        gpgkey: http://content/rhel10.0/x86_64/dvd/RPM-GPG-KEY-redhat-release

      ansible.builtin.yum_repository:

        gpgkey: http://content/rhel10.0/x86_64/dvd/RPM-GPG-KEY-redhat-release

Create an offline role named apache

httpd + firewall + templated index.html
▸
Task
Create an offline role named apache under the roles directory.
  1. Install the httpd package; the service should be started and enabled.
  2. Host the web page using template.j2.
  3. The template.j2 should contain: My host is HOSTNAME on IPADDRESS
    • Where HOSTNAME is the fully qualified domain name.
  4. Create a playbook named apache_role.yml and run the role on the dev group.
Answer
✓ Solution
init role
ansible-galaxy role init /home/student/ansible/roles/apache
roles/apache/templates/template.j2
My host is {{ ansible_fqdn }} on {{ ansible_default_ipv4.address }}
# or
My host is {{ ansible_facts['fqdn'] }} on {{ ansible_facts['default_ipv4']['address'] }}
roles/apache/tasks/main.yml
- name: Install httpd package
  ansible.builtin.dnf:
    name:
      - httpd
      - firewalld
    state: present
- name: start service httpd
  ansible.builtin.service:
    name: httpd
    state: started
    enabled: yes
- name: start service firewalld
  ansible.builtin.service:
    name: firewalld
    state: started
    enabled: yes
- name: Add http service in firewall rule
  ansible.posix.firewalld:
    service: http
    state: enabled
    permanent: yes
    immediate: yes
- name: Copy the template.j2 file to web server directory
  ansible.builtin.template:
    src: template.j2
    dest: /var/www/html/index.html
/home/student/ansible/apache_role.yml
---
- name: apache deploy
  hosts: dev
  roles:
    - apache

Web content & permissions — webcontent.yml

/devweb dir, SELinux context, symlink
▸
Task
Create a playbook webcontent.yml and run it on the dev group.
  1. Create a directory /devweb owned by the devops group.
  2. /devweb should have context type httpd (httpd_sys_content_t).
  3. Permissions: user=rwx, group=rwx, others=rx, and the group special (setgid) permission should be applied to /devweb.
  4. Create /devweb/index.html with content Development.
  5. Link the /devweb directory to /var/www/html/devweb.
Answer
✓ Solution
/home/student/ansible/webcontent.yml
---
- name: create a link
  hosts: dev
  tasks:
    - name: create a directory
      ansible.builtin.file:
        path: /devweb
        state: directory
        group: devops
        mode: '02775'
        setype: httpd_sys_content_t
    - name: create a file
      ansible.builtin.file:
        path: /devweb/index.html
        state: touch
    - name: copy the contents to index.html
      ansible.builtin.copy:
        content: "Development\n"
        dest: /devweb/index.html
    - name: link the directory
      ansible.builtin.file:
        src: /devweb
        dest: /var/www/html/devweb
        state: link
Run & Verify:
run

Hardware report — hwreport.yml

gather facts, default NONE
▸
Task
Collect a hardware report using a playbook on all nodes. Playbook name hwreport.yml.
  1. Download hwreport.txt from http://workstation/Rhce/hwreport.txt and save it under /root.
  2. If there is no information, it must show NONE.
  3. Collect: HOSTNAME, MEMORY, BIOS, CPU, DISK_SIZE_SDA, DISK_SIZE_SDB.
Answer
✓ Solution
/home/student/ansible/hwreport.yml
---
- name: hwreport
  hosts: all
  ignore_errors: yes
  tasks:
    - name: Download the file
      ansible.builtin.get_url:
        url: "http://workstation/Rhce/hwreport.txt"
        dest: /root/hwreport.txt
    - name: Collect report 1
      ansible.builtin.set_fact:
        HOSTNAME: "{{ ansible_hostname }}"
        MEMORY: "{{ ansible_memtotal_mb }}"
        BIOS: "{{ ansible_bios_version }}"
        CPU: "{{ ansible_processor }}"
        DISK_SIZE_SDA: "{{ ansible_devices['sda']['size'] }}"
    - name: Collect report 2
      ansible.builtin.set_fact:
        DISK_SIZE_SDB: "{{ ansible_devices['sdb']['size'] }}"
    - name: Copy the content to the managed node
      ansible.builtin.copy:
        content: |
          #hwreport
          HOSTNAME={{ HOSTNAME | default('NONE') }}
          MEMORY={{ MEMORY | default('NONE') }}
          BIOS={{ BIOS | default('NONE') }}
          CPU={{ CPU | default('NONE') }}
          DISK_SIZE_SDA={{ DISK_SIZE_SDA | default('NONE') }}
          DISK_SIZE_SDB={{ DISK_SIZE_SDB | default('NONE') }}
        dest: /root/hwreport.txt
Run & Verify:
run

Create users & groups — users.yml

vault + user_list.yml, SHA512
▸
Task
Download http://localhost/Rhce/user_list.yml. Playbook name users.yml, run on all nodes using two variable files user_list.yml and vault.yml.
  1. Developers:
    • Create a group opsdev.
    • Create users from the users variable whose job = developer, and add them to the opsdev group.
    • Assign the password in SHA512 format; the user password is {{ pw_developer }}.
    • Run on the dev and test host groups.
  2. Managers:
    • Create a group opsmgr.
    • Create users from the users variable whose job = manager, and add them to the opsmgr group.
    • Assign the password in SHA512 format; the user password is {{ pw_manager }}.
    • Run on the test host group.
  3. Use a when condition for each play.
Answer
✓ Solution
get variable file
wget http://localhost/Rhce/user_list.yml
/home/student/ansible/users.yml
---
- name: Create an users and groups
  hosts: all
  vars_files:
    - user_list.yml
    - vault.yml
  tasks:
    - name: Create group 1
      ansible.builtin.group:
        name: opsdev
        state: present
      when: inventory_hostname in groups['dev'] or inventory_hostname in groups['test']

    - name: Create group 2
      ansible.builtin.group:
        name: opsmgr
        state: present
      when: inventory_hostname in groups['test']

    - name: User create 1
      ansible.builtin.user:
        name: "{{ item.name }}"
        uid: "{{ item.uid }}"
        password: "{{ pw_developer | password_hash('sha512') }}"
        password_expire_max: "{{ item.password_expire_days }}"
        groups: opsdev
        state: present
      loop: "{{ users }}"
      when: item.job == "developer" and (inventory_hostname in groups['dev'] or inventory_hostname in groups['test'])

    - name: user create 2
      ansible.builtin.user:
        name: "{{ item.name }}"
        uid: "{{ item.uid }}"
        password: "{{ pw_manager | password_hash('sha512') }}"
        password_expire_max: "{{ item.password_expire_days }}"
        groups: opsmgr
        state: present
      loop: "{{ users }}"
      when: item.job == "manager" and inventory_hostname in groups['test']
Run & Verify:
run
ansible-navigator run users.yml --vault-password-file=secret.txt -m stdout
# fallback: ansible-playbook users.yml --vault-password-file=secret.txt
ansible dev  -m command -a 'tail /etc/group'
ansible test -m command -a 'tail /etc/group'

Task 17.1 — lvm.yml
Create a logical volume named data of 700M from the volume group research; if 700M cannot be created, then create at least 300M. Playbook name lvm.yml, run on all nodes.
  1. If the VG does not exist, debug the message "vg not found".
  2. If the 700M LV size is not created, debug the message "Insufficient size of vg".
  3. If the logical volume is created, assign the file system as ext3.
  4. Do not perform any mounting for this LV.
✓ Solution 17.1
/home/student/ansible/lvm.yml
---
- name: Creating LVM storage
  hosts: all
  ignore_errors: yes
  tasks:
  - name: Check Volume group is present
    ansible.builtin.command: vgdisplay research
    register: vginfo
  - name: Debug Message
    ansible.builtin.debug:
      msg: "vg not found"
    when: vginfo is failed
  - name: Creating LV of size 700MB
    community.general.lvol:
      vg: research
      lv: data
      size: 700m
      state: present
    when: vginfo is success
    register: lv1
  - name: Debug Message
    ansible.builtin.debug:
      msg: "Insufficient size of vg"
    when: lv1 is failed
  - name: Create LV of 300MB
    community.general.lvol:
      vg: research
      lv: data
      size: 300m
      state: present
    when: lv1 is failed
  - name: Assign filesystem as ext3
    community.general.filesystem:
      device: /dev/research/data
      fstype: ext3
    when: vginfo is success
run & verify
ansible-navigator run lvm.yml -m stdout   # or: ansible-playbook lvm.yml
ansible all -m command -a 'lsblk -fp'

Task 17.2 — partition.yml
Create a playbook named partition.yml and make a file system on the balancers group.
  1. Create a partition of size 1500MiB on sdb with number 1.
  2. Format it with ext4 and mount on /newpart.
  3. Create a partition of size 1500MiB on sdc with number 1.
  4. If 1500MiB cannot be created, print: "disk doesn't have enough space to create partition".
  5. At least an 800MiB partition should be created.
  6. Format it with ext4 and mount on /newpart1.
  7. If disk vdd is not found, print: "disk not found".
✓ Solution 17.2
/home/student/ansible/partition.yml
---
- name: create partition on two disk
  hosts: balancers
  ignore_errors: yes
  tasks:
    #### sdb disk ####
    - name: list and register the disk sdb
      community.general.parted:
        device: /dev/sdb
        state: info
      register: sdbinfo
    - name: create partition on disk sdb with size 1500MiB
      community.general.parted:
        device: /dev/sdb
        state: present
        number: 1
        part_start: 1MiB
        part_end: 1500MiB
      when: sdbinfo is success
      register: sdb1
    - name: format file system on sdb1 partition with ext4
      community.general.filesystem:
        device: /dev/sdb1
        fstype: ext4
        force: yes
      when: sdb1 is success
    - name: mount the sdb1 with ext4 on /newpart
      ansible.posix.mount:
        src: /dev/sdb1
        path: /newpart
        fstype: ext4
        state: mounted
      when: sdb1 is success

    #### sdc disk ####
    - name: list and register the disk sdc
      community.general.parted:
        device: /dev/sdc
        state: info
      register: sdcinfo
    - name: create partition on disk sdc with size 1500MiB
      community.general.parted:
        device: /dev/sdc
        state: present
        number: 1
        part_start: 1MiB
        part_end: 1500MiB
      when: sdcinfo is success
      register: sdc1
    - ansible.builtin.debug:
        msg: "disk doesn't have enough space to create partition"
      when: sdc1 is failed
    - name: create partition on disk sdc with atleast 800MiB
      community.general.parted:
        device: /dev/sdc
        state: present
        number: 1
        part_end: 800MiB
      when: sdc1 is failed
    - name: format file system on sdc1 partition with ext4
      community.general.filesystem:
        device: /dev/sdc1
        fstype: ext4
        force: yes
      when: sdcinfo is success
    - name: mount the sdc1 with ext4 on /newpart1
      ansible.posix.mount:
        src: /dev/sdc1
        path: /newpart1
        fstype: ext4
        state: mounted
      when: sdcinfo is success

    #### vdd disk ####
    - name: list and register the disk vdd
      community.general.parted:
        device: /dev/vdd
        state: info
      register: vddinfo
    - ansible.builtin.debug:
        msg: "disk not found"
      when: vddinfo is failed
